## Overview

This project addresses the critical challenge of wildlife monitoring in dense forest areas during nighttime conditions. Using Convolutional Neural Networks (CNNs) built with TensorFlow and Keras, the system classifies night-vision camera images to detect the presence of tigers in real time.

## Key Features

- **CNN Architecture**: Designed a multi-layer convolutional neural network optimized for image classification tasks on low-resolution, low-light imagery.
- **Image Augmentation**: Applied rotation, flipping, zoom, and brightness adjustment techniques to expand the training dataset and improve model robustness.
- **Night Vision Support**: Specifically trained on infrared and night-vision image datasets to handle real-world nocturnal forest surveillance conditions.
- **High Accuracy**: Achieved reliable detection rates through iterative model tuning, dropout regularization, and batch normalization.

## Technologies Used

- **Python** with TensorFlow / Keras for deep learning model development
- **OpenCV** for image preprocessing and augmentation
- **NumPy & Pandas** for data manipulation
- **Matplotlib** for training visualization and performance metrics

## Challenges and Learnings

The primary challenge was working with low-quality night-vision images where traditional object detection approaches struggled. Data augmentation proved essential for preventing overfitting on the limited dataset. This project deepened my understanding of CNN architectures, transfer learning considerations, and the practical challenges of deploying ML models for wildlife conservation.

## Outcome

The classifier successfully identifies tiger presence in night-vision footage with high confidence, demonstrating the potential for AI-driven wildlife monitoring systems that can operate autonomously in remote forest environments.
